Exercise 8.1 – ENABLING/DISABLING JAVASCRIPT

Đây là bài thao tác thủ công trong trình duyệt theo tài liệu gốc.

  1. Tìm mục quản lý JavaScript trong phần Settings / Site settings của trình duyệt.
  2. Bật JavaScript, truy cập JavaScriptTest.php, ghi nhận thông báo “You have JavaScript enabled”.
  3. Tắt JavaScript và tải lại trang để kiểm tra thông báo “You have JavaScript disabled”.
  4. Bật lại JavaScript sau khi hoàn tất.

Chú ý: URL từ tài liệu năm 2017 có thể không còn hoạt động. Khi đó có thể dùng trang thử nghiệm nội bộ để kiểm tra hai trạng thái. Đây là công cụ bổ sung, không thay thế URL gốc.
