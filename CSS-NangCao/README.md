## Chạy trang

Mở `index.html` trong trình duyệt hoặc chạy bằng Live Server. Chọn bài thực hành trên trang chủ để mở trực tiếp trang HTML tương ứng. Thử thu hẹp cửa sổ hoặc dùng chế độ thiết bị di động trong DevTools để kiểm tra các bài responsive; rê chuột hoặc tải lại trang để xem hiệu ứng.

## Triển khai GitHub Pages

1. Đẩy nội dung thư mục này lên một repository GitHub.
2. Trong repository, vào **Settings → Pages**.
3. Ở **Build and deployment**, chọn **Deploy from a branch**, sau đó chọn nhánh `main` và thư mục `/(root)`.
4. Lưu cấu hình và mở URL Pages do GitHub hiển thị trong phần **Settings → Pages**.

Trang sử dụng các đường dẫn tương đối nên hoạt động ở cả máy local và GitHub Pages, kể cả khi được triển khai dưới đường dẫn repository.
