# FocusQuest Full-stack

Từ thư mục FocusQuest chạy `npm install`, `npm start` rồi mở http://localhost:3000. Giao diện trong `public/`, Express và repository SQLite trong `server/`. Kiểm tra nhanh API tại `/api/health`, `/api/tasks?scope=today`, `/api/analytics/overview`. Chạy `npm test` để kiểm thử tích hợp.
